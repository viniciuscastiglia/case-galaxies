# Lote da noite 2: F23, F16, M8, base v2 e abertura — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** deixar prontos, sem abrir resultado nenhum, o rastreio do modelo de uso (F23, #37), o código do teste final
(F16), o `top_drivers` (M8), a base v2 da #33 e o script que monta a abertura das hipóteses (#36).

**Architecture:** cada peça num arquivo próprio, reusando as funções do runner (`previa.experimento`) e do modelo
(`previa.modelo`); nada recalcula métrica nem feature por conta própria (princípio 4). O teste final e a abertura
são comandos que só o controlador roda, com o Vinicius presente.

**Tech Stack:** LightGBM 4.7, MLflow 3.16, shap 0.52, pandas 3, pytest.

**Spec:** `docs/AUDITORIA.md` (seção 3: "prever_criativo e o bundle", "M8", "O teste final"; F16, F23), `docs/DECISOES.md`
(#5, #33, #34, #36, #37), `HIPOTESES.md` (H1), `CLAUDE.md`.

## Global Constraints

- **Nada abre resultado.** Nenhum subagente lê métricas do MLflow de runs reais, `data/ablacao/*.csv`, `data/logs/h*.log`
  nem chama `carregar_base(final=True)` fora de testes com base sintética. Os testes usam `previa.sintetico.gerar_base`
  e a fixture `mlflow_temporario` (`tests/test_experimento.py:527`), nunca o `mlflow.db` real.
- Treino e uso pelas mesmas funções: `preparar`, `treinar_gbm`, `prever_absoluto`, `avaliar`, `registrar`,
  `treinar_bundle`, `contribuicoes`, `agrupar_blocos`.
- Caminhos por `previa.caminhos` (`DADOS`, `CONFIGS`, `ARTEFATOS`); parâmetros em `configs/`, nunca no código.
- Falha nunca silenciosa (princípio 7): erro com mensagem que diz o que fazer.
- Código e comentários em português, no estilo dos módulos vizinhos; docstring de módulo citando a aula.
- **Subagentes não fazem commit** (vários no mesmo checkout); o controlador faz o commit de cada tarefa.
- Verificação: `uv run pytest`, `uv run ruff check .`, `uv run ruff format src tests`.

## Review Focus

- O teste final aberto duas vezes por engano: o segundo comando recusa e diz quando foi a primeira abertura (Task 2).
- Uma linha do teste no treino final, ou um canal "novo" no treino do canal novo (Task 2).
- `model_version` sem o run id, ou um pacote salvo cujo arquivo difere do artefato do run (Task 1).
- Um driver de contexto (`hist_*`, setor) ou de um bloco não aprovado na lista do `top_drivers` (Task 3).
- A base v2 sobrescrevendo a v1, ou a v1 deixando de ser a base das avaliações (Task 4).

### Task 5: o script da abertura (#36)

**Files:** Create `src/previa/abertura.py`, `configs/abertura.yaml`; Test `tests/test_abertura.py`.

**Interfaces — Produces:**
- `configs/abertura.yaml`: uma entrada por hipótese (H2 a H11), com `controle` e `tratamento` como **nomes de config**
  (`configs/experimentos/*.yaml`, conforme o `HIPOTESES.md`), e o caminho da tabela da ablação

  ruído) e o veredito da #36 ("argumento" só se sólido nas três).
